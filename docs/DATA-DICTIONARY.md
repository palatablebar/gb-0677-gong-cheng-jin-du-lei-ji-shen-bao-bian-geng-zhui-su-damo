# 计量定义

claim_id唯一；item为清单编码，支持钢筋与001等别名。period为YYYY-MM。累计数量按t或m³保存，当前周期工程量=本次累计-前期已审累计。previous_revisions参数可指定更正后的前审数量，重新计算形成不同批次，不覆盖旧证据。

C0原始价100元，C1自2026-11生效为120元，DRAFT未批准不可结算。负进度必须reversal=approved作为已批冲回标记。可选列voucher_id为冲回凭证号（缺省取claim_id），reversal_of显式指向原申报；未给出时按同清单更早周期仍有额度的正向申报推断，再退化到该笔previous_qty。冲回采信量=min(凭证量,原已签量−已冲回量)，超出记reversal_excess并从净进度排除；未落地原单记ORIGIN_NOT_FOUND，同批重复凭证记DUPLICATE_VOUCHER，已签批次用过的凭证记REPLAY_VOUCHER，均不进入正式结果。扣留质保金5%、预付款扣回10%分别按分量化，净额=本期总额-质保金-预付款扣回，负进度同步冲回扣留。reported为原申报净额，差异=复算净额-reported。

业务ID和超大整数按文本保形；Decimal参与数量金额计算，对外序列化为字符串。哨兵集合定义在app/values.py，缺失值不能当零。所有时间带UTC偏移，先转UTC比较，业务日按指定地区划分。区间统一[start,end)。重复业务键保留第一条、完全相同行计重复；值冲突行隔离且保留原值。空文件、全空白、仅表头分开拒绝。

批次号由输入、规则版本与显式参数决定；已签冲回台账通过上下文注入，不改变批次号，但会在签认时逐笔核验。运行清单包括输入sha256、规则版本、参数、生成时刻与耗时。源行编号以CSV解析器的物理结束行号表示，引号内换行不增加记录数。输入超过4MB返回413，非法表头和类型返回422，失效版本复核返回409。
